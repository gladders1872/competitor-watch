How this works

A GitHub Action scans each competitor's XML sitemap every day. It records pages that were added, removed or had their lastmod date change. For new and changed pages it also reads the title, meta description, H1, H2s, canonical and HTTP status.

Each page is sorted into a content type (blog, webinar, whitepaper and so on) from its URL and title, and checked against the client's keyword groups. A keyword alert fires when a matching page is added or removed, or when a changed page gains or loses one of your terms.

To change competitors, keywords, content types or exclusions, edit config/clients.yaml in the repository. There is no limit on the number of competitors.
